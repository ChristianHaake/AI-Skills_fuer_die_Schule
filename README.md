# AI-Skills für die Schule

Eine kuratierte Sammlung von KI-Skills, Tools und Open Educational Resources (OER) für den schulischen Einsatz — mit Fokus auf **Datenschutz, lokale Verarbeitung und freie Lizenzen**.

Die Sammlung ist **kuratiert**, keine vollständige Marktübersicht und kein objektives Ranking. Empfohlen wird, was aus praktischer Nutzung in der Schule sinnvoll erscheint und sich kurz begründen lässt.

## Lernplattformen & Assistenten

### [AIS.chat](https://app.ais-chat.schule)

- **Zweck:** Plattform für KI-gestützte Lernszenarien, Dialogpartner und Assistenten im Unterricht.
- **Warum here:** Speziell für Schule entwickelt, DSGVO-konform, deutsche Server, freie Konfigurierbarkeit via Skills.
- **Lizenz:** Plattform proprietär, Skills CC BY-SA 4.0
- **Quelle:** [3ducation.org → AIS.chat](https://3ducation.org)

### [Pinnwand zur Projektplanung](https://3ducation.org/allgemein/pinnwand.html)

- **Zweck:** Vielseitig einsetzbare, leichtgewichtige digitale Pinnwand zur Projektplanung mit Anschlussmöglichkeit zur KI-Weiterarbeit.
- **Warum here:** Keine Accounts nötig, lokal im Browser, AGPL-3.0, direkt im Unterricht einsetzbar.
- **Lizenz:** AGPL-3.0-or-later
- **Quelle:** [3ducation.org](https://3ducation.org/allgemein/pinnwand.html)

### [Unterrichtsplanung-App](https://github.com/dk-3du/unterrichtsplanung)

- **Zweck:** Native macOS-App (Swift/SwiftUI, macOS 26+) zur Unterrichts- und Vorhabenplanung sowie Materialkuration — **alles lokal, verschlüsselt (AES-256, Secure Enclave), App Sandbox**.
- **Warum here:** Maximale Datensicherheit, keine Cloud, GPL-3.0, für Apple Silicon optimiert, Web-App als Leseschnittstelle für iPad.
- **Lizenz:** GPL-3.0-or-later (App), AGPL-3.0-or-later (Web-App)
- **Quelle:** [GitHub: dk-3du/unterrichtsplanung](https://github.com/dk-3du/unterrichtsplanung)

## Unterrichts-Tools (lokal/datenschutzfreundlich)

### [QR-Code-Generator](https://3ducation.org/allgemein/qrcodegenerator.html)

- **Zweck:** Einfaches Webtool zur schnellen, datensparsamen Erzeugung von QR-Codes.
- **Warum here:** Kein Tracking, keine Accounts, AGPL-3.0, funktioniert offline nach erstmaligem Laden.
- **Lizenz:** AGPL-3.0-or-later
- **Quelle:** [3ducation.org](https://3ducation.org/allgemein/qrcodegenerator.html)

### [Scratch SB3 Merger](https://3ducation.org/dw/scratch-sb3-merger.html)

- **Zweck:** Webtool zum Verschmelzen von zwei `.sb3`-Dateien für Teamarbeit an gemeinsamen Scratch-Projekten.
- **Warum here:** Löst echtes Kollaborations-Problem im Informatik-Unterricht, AGPL-3.0, lokal im Browser.
- **Lizenz:** AGPL-3.0-or-later
- **Quelle:** [3ducation.org](https://3ducation.org/dw/scratch-sb3-merger.html)

### [KomPo7-Beobachtungstool](https://lbs-50.de/kompo7/)

- **Zweck:** Hilfsmittel zur strukturierten Beobachtungsdokumentation für Berufsorientierung (Klasse 7).
- **Warum here:** Praxiserprobt, AGPL-3.0, strukturierte Erfassung statt Freitext-Chaos.
- **Lizenz:** AGPL-3.0-or-later
- **Quelle:** [lbs-50.de](https://lbs-50.de/kompo7/)

## Status der Informationen

Die Sammlung führt technische Statusdaten, damit veraltete Angaben sichtbar werden:

- Erreichbarkeit der offiziellen Projektseite
- Letzte veröffentlichte Version / letzter Release
- Aktivität eines offiziellen Repositories
- Lizenz
- Plattform-Support (macOS, iPadOS, Browser, Linux, Windows)
- Preis- / Tarifangaben, soweit öffentlich

**Die technische Prüfung beurteilt nicht, ob ein Tool weiterhin empfehlenswert ist — das bleibt redaktionelle Entscheidung.**

Details zu Automatisierung und redaktionellen Regeln stehen im [Hintergrunddokument](docs/automatisierung-und-regelwerk.md).
